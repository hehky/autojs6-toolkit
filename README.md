# AutoJs6 通用定位点击工具链

在安卓手机上自动操作任意 App：先看清界面，再定位点击，点不中就录一遍。免 root，需开启无障碍。

| 脚本 | 作用 |
|---|---|
| `toolkit.js` | 主程序，单文件整合版（约 1500 行） |
| `app_clicker_v7.js` | 通用定位点击器（五级定位链 + 录制生成脚本） |
| `analyze_view.js` | 界面结构分析器 |
| `probe.js` | 环境探针（插件与权限检测） |
| `taobao_vip_full.js` | 淘宝会员领红包 v4.2 |
| `ima.js` | ima 每日签到领算力 v2.0（AutoX.js） |

## 1. toolkit.js — 主程序
一次运行，菜单选择：环境情报 / 界面分析 / 定位点击 / 坐标探测 / 录制 / 回放（断点续传）/ 全链路。由 `probe.js`、`analyze_view.js` 和定位点击器整合而成，录制每步持久化，中断不丢。

## 2. app_clicker_v7.js — 通用定位点击器
三种模式：① 按文字/描述定位并点击；② 点一下得坐标；③ 分步录制，点一步记一步，最后自动生成脚本。

定位链逐级兜底：录制坐标 → 文字/描述（支持同义词组）→ 控件 ID → 邻近文字偏移 → 模板图匹配 → 视觉模型（可选，默认关）。命中“已领取”等终态词自动跳过；失败位置写入本地记忆，下次先试。

## 3. analyze_view.js — 界面结构分析器
1–2 秒列出当前页面上半部可点控件的类名、ID、位置、文字和描述，用来把点击写成结构规则：App 改版只要 ID 不变就还能找到。

## 4. probe.js — 环境探针
扫描本机已装的 AutoJs 插件和同系应用，读取版本与插件 SDK，尝试加载，给出结论和权限提示，报告导出为 JSON 和 TXT。

## 5. taobao_vip_full.js — 淘宝会员领红包 v4.2
路径：我的淘宝 → 会员中心 → 一键领取 → 查看更多。先认文字锚，认不到才用录制坐标；后台守卫持续关广告弹窗，误触“确定关闭当前模块”时只返回、不确认。

## 6. ima.js — ima 每日签到领算力 v2.0（AutoX.js）
自动走完：我的 copilot → 设置 → 用量统计 → 领取算力 → 签到。文字匹配优先，全失败才用按屏幕比例的坐标兜底，可设为只认文字、绝不盲点。

## 使用
安装 AutoJs6（`ima.js` 用 AutoX.js）→ 开启无障碍 → 导入脚本 → 运行。

新 App 建议流程：先跑界面分析，再录制，最后回放。
